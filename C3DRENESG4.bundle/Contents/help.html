Description

O C3DRENESG  é um programa de dimensionamento de redes de drenagem e esgoto urbanos que roda dentro do Autodesk® Civil3D®.

Ele usa o recurso de PipeNetworks, tornando o lançamento das redes e perfis muito prático e rápido.

Com ele é possível dimensionar as redes, verificar a capacidade, calcular a escavação de valas para a tubulação, obter notas de serviço e muito mais.

O processo de cálculo é iterativo e se pode verificar interferência com outras redes ao mesmo tempo que se calcula a rede.

Use o C3drenesg para lançar e dimensionar redes de drenagem e esgoto urbanos e também para calcular sarjetas e valas.

Instalação/Desinstalação

O instalador que executou quando você baixou este aplicativo / plug-in da Autodesk App Store instala o aplicativo / plug-in. OU, basta clicar duas vezes no instalador baixado para instalar o aplicativo / plugin. Talvez seja necessário reiniciar o produto Autodesk para ativar o aplicativo / plug-in. Para desinstalar este plug-in, saia do produto Autodesk se você estiver executando no momento, basta reiniciar o instalador e selecione o botão "Desinstalar". OU, clique em Painel de controle> Programas> Programas e recursos (Windows 7/8.1/10) e desinstale como você faria com qualquer outro aplicativo do seu sistema.

Problemas conhecidos

Pode ser que o Windows bloqueie as DLLs do programa. Para evitar isso, clique o botão direito do mouse sobre as DLLs, clique Propriedades e clique o botão Desbloquear. O mesmo deve ser feito com os arquivos de ajuda (*.chm)
