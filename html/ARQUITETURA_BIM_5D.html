💎 ESTRUTURA DE DADOS — BIM 5D 3D + TEMPO + CUSTO + MEDIÇÃO

O modelo central de dados

Cada trecho da rede é um objeto que carrega 5 dimensões: geometria 3D (coordenadas, DN, material), tempo (fase do cronograma, data prevista/real), custo (SINAPI por serviço), medição (% executado, BM aprovado) e as-built (dados de campo real). Tudo nasce da Nota de Serviço e termina no Cadastro NTS 292.

🎯 FLUXO DO CONTROLE DE OBRA — 5D na Prática

FASE 1
📁 Receber Projeto
DXF (legado) ou DWG Civil 3D (novo). Rodar ler_dxf_gdal ou ler_landxml. Resultado: pvs + trechos padronizados.
FASE 2
📋 Gerar NS de Campo
Rodar gerar_ns.py. Cada trecho vira uma NS com PDF A4 pro encanador. Imprimir e levar pra obra.
FASE 3
🔧 Criar Pipe Network
Importar LandXML no Civil 3D com catálogo SABESP (PVC_SABESP.xml). Pipe Network nativo com geometria real.
FASE 4
💰 Montar 5D
Rodar gerar_ifc_lod500.py + gerar_project_xml.py. Cada tubo recebe custo SINAPI. Cronograma por fase.
FASE 5
🏗️ Executar Obra
Encanador executa conforme NS. Topógrafo mede o as-built. Dados voltam pro sistema (CT/CF reais).
FASE 6
📊 Medir (BM)
Boletim de Medição por trecho executado. Pagamento condicionado ao cadastro (contrato pág. 64). Vincular NS → BM.
FASE 7
📐 Cadastro NTS 292
Rodar gerar_cadastro_nts292.py com dados as-built reais. DXF georref + PDF assinado → SIGNOS via VisualBIM.
FASE 8
💎 Controlar no ConstruData
Viewer 3D mostra: verde=executado, amarelo=em andamento, vermelho=atrasado. Custo acumulado = curva S.
