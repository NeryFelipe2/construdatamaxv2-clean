📋 A NS é a UNIDADE CENTRAL do sistema

Cada NS = 1 trecho da rede (PV_A → PV_B). Toda medição, todo custo, todo cronograma referencia a NS.
NS_001_ESG = trecho esgoto | NS_001_AGU = trecho água.
A NS vai pro campo (PDF) → volta com dados as-built → gera cadastro → gera medição → fecha o ciclo 5D.
